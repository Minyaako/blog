# 木漏日：给 Galgame 与同人游戏做一个顺手的桌面游戏库

最近看到了kungal的大佬推出了一个非常强力的api，[nextmoe](https://developer.nextmoe.dev/)。其不只是包含了目前为止最全的galgame数据，更包含了一个非常厉害的功能，其与letmoe平台一起，托管并且提供很多galgame的直链下载。这就指向了一个非常好的前景：我们终于可以做一个入口，把找作品、收藏、下载、整理和游玩记录接在一起，让游戏库更接近自己平时使用软件的习惯。

于是就有了 **木漏日 · Komorebi**，一个面向 Galgame 与同人游戏玩家的 Windows 桌面游戏管理器。设计的初衷是提供类似steam的一站式服务。目前已经发布 v1.0，并在继续迭代。

项目地址：[Minyaako/Komorebi](https://github.com/Minyaako/Komorebi)  
下载地址：[GitHub Releases](https://github.com/Minyaako/Komorebi/releases/latest)

## 从作品出发，慢慢整理自己的游戏库

我希望游戏库能装下“已经下载的游戏”，也能装下“以后想玩的作品”。

在木漏日里，找到一部感兴趣的作品后，可以先加入库，等有时间再选择资源安装。作品详情页集中展示介绍、标签和可用资源；看到喜欢的会社、创作者或系列，并且支持沿着关联继续浏览。

搜索也尽量围绕玩家实际找游戏的方式展开：除了名称和标签，还提供会社、创作者、角色、系列等查询入口。标签支持包含和排除条件，作品列表支持排序、直链筛选和滚动加载。搜索结果、作品详情和标签之间来回跳转时，可以用前进、后退按钮返回，并保留之前的搜索条件和滚动位置。


## 已有的游戏，也能一起收进来

对于已经放在硬盘里的游戏，可以选择文件夹扫描，匹配作品资料后加入游戏库。匹配不合适时，再通过名称搜索选择对应作品。

游戏库支持多个存储位置，可以把游戏分开放在不同磁盘。展示方式提供卡片和封面拼贴（这是我今年最喜欢的平面设计之一），双击作品进入详情页；“待玩”“在玩”“已通关”等状态用于记录进度，收藏集则留给自己组织。

我倾向于把分类权交给使用者，这样更体现灵活性与轻便性。可以建一个“准备开坑”，也可以按会社、系列或自己的喜好建收藏集。右键游戏后，选择已有收藏集就能加入，也可以直接输入名字创建新的收藏集。

后续我们也会支持从其他管理器直接导入，这样也方便了无缝的切换

## 把下载、解压和入库接起来

下载与上传集中放在一个任务页面里，方便查看进度和处理异常。

直链下载使用 aria2，支持暂停和继续。下载完成后，客户端会检查压缩包条目并自动解压入库；遇到密码问题，可以补充密码后重试。资源说明支持 Markdown 渲染，方便阅读版本说明、使用方法和其他备注。

对于网盘资源，实际下载仍由网盘客户端完成。目前的处理是：木漏日可以监听指定下载目录，发现下载完成的文件后，将其整理到对应位置，并标为“待操作”，留给用户检查和处理。

最关键的是，虽然api并没有直接提供上传的能力，但是我们通过letmoe的上传接口，提供了高度自动化的一键上传体验。你可以通过网盘下载资源，再上传letmoe的方式，为直链资源的丰富添砖加瓦，共同构建一个更强大的平台。

目前“找到作品—选择资源—下载整理—加入游戏库”这条主要流程已经完整接通，后续我们会继续打磨细节，完善交互体验。

## 给玩过的故事留一点记录

木漏日支持通过 NextMoe OAuth 登录，查看个人资料，并管理游戏状态、评分和笔记。其中，私人笔记保存在本机，可以记录一些不方便分享的感想。

从客户端启动游戏后，会记录游玩时长，并在个人页用热力图展示每日活动。时长可以同步到 NextMoe，让本地游戏库与账号记录产生联系。


桌面使用上，木漏日支持托盘后台运行，关闭主窗口后可以继续下载和计时；也提供主题切换、右键操作和横幅图片缓存。界面布局主要是借鉴了 Steam 的一些习惯，毕竟作为一个广泛使用的游戏平台，他的操作逻辑是久经打磨的，然后围绕 Galgame 与同人游戏的使用场景调整，使其更符合我们的操作习惯。

## 核心在线能力来自 LetsMoe 与 NextMoe

这部分值得再次说明：**木漏日的核心在线能力来自 LetsMoe（LetMoe·一启萌）与 NextMoe API。**

作品目录、标签、资源服务和账号授权，依托平台提供的能力。木漏日主要做的是把它们与本地文件管理、下载任务和游玩记录连接起来，提供一个更顺手的桌面入口。

它是独立的第三方客户端，不提供任何服务端能力

。资源访问使用用户自己的账号与本地保存的个人密钥，具体可用性取决于平台提供的资源及权限。

也希望使用木漏日的朋友，愿意一起维护这个资源环境：补充准确的作品资料，反馈失效链接和错误关联，分享时写清来源、语言、版本、密码与启动方式。准备上传的文件，也记得检查完整性并排除自己的存档和私人信息。

客户端的体验，离不开这些日常维护。感谢 LetsMoe、NextMoe 的维护者，也感谢每一位整理资料、分享作品和修复资源的人。

## 最近还在继续做什么

v1.0 发布后，开发版又补了一些日常使用中很容易遇到的问题：

- **模糊搜索**：库内搜索忽略大小写、全半角、空格和标点，并容忍少量错字；在线搜索没有直接结果时，会尝试召回近似候选。例如输入 `clanad`，也能找到 CLANNAD。标签包含与排除仍保持严格匹配。
- **启动与计时**：启动后按钮切换为“结束游戏”，并补充启动器转交子进程后的跟踪，让计时更贴近实际游玩过程。
- **安装包清理**：成功安装并保存入库记录后，自动删除客户端下载的压缩包，减少重复占用空间；失败包和手动导入的原包保留。
- **个人密钥申领**：接入系统 Edge 或 Chrome，在用户完成官方登录后自动办理个人应用与密钥申领、验证和本机加密保存，减少手动填写和复制。

这些是近期开发版的进展，是否已随安装包提供，以对应 Release 的更新说明为准。

接下来，我想继续把基础体验磨好：统一界面的字号、间距和图标，完善不同窗口尺寸下的布局与动效；继续改进多语言别名搜索、本体与补丁的安装流程、大型游戏库的加载速度，以及数据备份和版本更新体验。

## 下载试试

目前提供 Windows x64 安装版和便携版。安装版带中文安装向导和开始菜单入口；运行所需的桌面环境、下载引擎与解压工具已经随包提供，无需另外安装 Node.js、aria2 或 7-Zip。

如果你也希望把 Galgame 和同人游戏整理到一个更顺手的桌面入口里，可以下载试试。遇到问题，或者有具体的使用习惯希望被照顾到，欢迎提交 Issue。相比单纯增加功能，我更想把这些经常发生的小操作做好。
