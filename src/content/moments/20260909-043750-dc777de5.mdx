是的，这是一个新功能。

介于短内容无需单独更新一篇博文，还有的时候要进行一些更短的记录，于是开发了moments板块。

正如你所见，这个板块实际上也是采取mdx的格式，因此md的语法也是**正常可用的**。

除此以外，这个板块有几同正式博文不同的：他有独特的图片分享机制，以及最重要的，它可以分享歌曲。


事实上，最近给博客添加了音乐库这个功能：其实没有别的原因，只是觉得这样很酷……你现在可以在右下角看到博客的音乐库。其实我还在里面加入了一些小彩蛋……比如一个隐藏歌单……？！

事实上，这次对博客的更新颇为巨大，比如说我还调整了

> 引用内容

和

```text
代码块
```

的样式，包括更完整的git式语义：

```diff
diff --git a/src/app.ts b/src/app.ts
--- a/src/app.ts
+++ b/src/app.ts
@@ -10,3 +10,3 @@
-const enabled = false
+const enabled = true
 console.log(enabled)
```

总之就是样式优化吧。

还有就是这个更新事实上应该早一点上线的，从这次分享的歌曲就能看出来，想更新的时候还是37.5的热天，今天就已经20℃了……

其实还有更大的更新，主要是围绕博客后台的。但是这个后台还没整理成一个可以公开的仓库，所以等下次再详细讲讲，主要就是重构了一下石山吧……

以上，新功能介绍完了。
