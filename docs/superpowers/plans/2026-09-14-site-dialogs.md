# 博客站内提示统一

目标：博客及内嵌 Waline 评论的 alert/confirm/prompt 全部使用站内弹窗，不改变权限、请求内容或草稿隔离规则。

范围（R2）：复用字体、主题、圆角，不加 UI 库；共享异步 dialog，具体动作按钮、输入校验、焦点恢复、键盘取消和移动端布局。保留既有页内状态与预览，不把连续自动保存状态变成弹窗。Waline 登录窗口和文件选择器不是提示框，不替换或绕过浏览器安全界面。

异步安全：等待确认时禁止重复动作；导航销毁和账号变化取消未决弹窗；确认后复查状态，取消不能变成批准。关闭标签页/刷新不能显示自定义离开框，因此移除 beforeunload 提示，保留即时保存、隐藏时尽力 flush、下载备份及站内跳转保护；不承诺存储失败时关闭页面不会丢数据。

执行：共享弹窗 → 榜单异步迁移与 Waline 局部适配 → 取消/批准/输入/导航/身份切换测试 → 桌面手机浅深色验证 → 独立审查。

验收：业务及实际评论不调用原生提示；取消不发写请求、不覆盖草稿；原因不能为空；导航后仍可用；无未决 promise 和重复提交；出现原生 dialog 事件即回归失败，保留多标签和审核闭环测试。

交付：先在工作区完成修改和验证。推送 main 会触发已恢复的自动部署，发布按用户明确要求执行。回滚前端不涉及数据库迁移。
