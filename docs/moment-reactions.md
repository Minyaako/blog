# 动态时间轴与快表情回应

动态列表将置顶记录单独放在最前面，其余内容按现有发布时间排序，以中国标准时间显示月份、日期和节点。窄屏保留月份与连线，把日历侧栏收进原有时间文字。标签页和详情继续使用同一动态卡片。

六个回应按固定索引保存：赞、喜欢、开心、惊讶、思考、庆祝，对应 Waline `reaction0` 到 `reaction5`。不要随意改变索引含义，否则历史数量会被错误解释。emoji 来自系统字体，无额外表情库或远程图片；只在 hover、键盘聚焦或点击成功时短暂动画，`prefers-reduced-motion` 下静止，不运行永久循环。

## 折叠与选择

卡片默认收起表情选择器，只显示服务器累计数量大于零的表情，以及一个「+」按钮。六项都是零时只显示「+」，不会铺开一排零计数。

点击「+」后展开六种表情，选择器内不重复显示计数。选择后收起面板，焦点回到「+」；新表情在服务器确认数量大于零后出现在卡片上。再次点击自己已选的外部表情可取消，累计数量归零时该按钮隐藏；只要其他人留下的累计数量仍大于零，该表情继续显示。也可直接点击已有表情切换选择。

Escape 或点击面板外部可收起选择器，Escape 会将焦点交回「+」。320px 窄屏使用 3×2 的选择网格，每个表情和「+」的触点至少为 44×44px；收起后不占用网格空间。加载中、预览环境或提交结果不明时，不允许通过「+」绕过原有提交限制。

## 计数与身份

- 复用现有 `https://comments.minyako.top/api/article` 接口，契约来自已安装的 `@waline/client@3.15.2` ArticleReaction 实现。GET 读取六项累计数量，POST 按 `type: reactionN` 与 `action: inc / desc` 更新；不新增数据库、不加载完整评论客户端。
- `path` 使用不可变动态 `id`，与动态详情的评论 key 一致，列表、标签和详情共享同一计数。
- 评论与快回应分开。无需登录，也不发送评论身份令牌或 cookie。每个浏览器记录一个已确认选择；再次点击取消，选择另一表情先取消原回应再添加新回应。
- 这是匿名累计回应次数，不是去重人数或防刷投票。换浏览器、清理本机存储不会删除服务器累计记录，也无法恢复原选择。
- 仅正式站点 origin `https://gsk.minyako.top` 且非预览构建时读写；本地、LAN、预览域名均停用，避免污染生产数据。服务端现有 Origin 限制继续生效。
- 卡片接近视口时才请求数量；翻页加载的新动态同样初始化，切页移除监听和读请求，不中断已经发送的写请求。

## 失败行为

数量仅使用服务器确认值；加载失败显示不可用与刷新按钮，不显示伪造的零。提交期间禁用按钮。支持 Web Locks 的浏览器会跨标签串行同一条动态的回应，其他浏览器以本机 pending 记录防止已在途重复提交，但匿名接口本身不提供多设备去重。

切换是两个独立请求，不宣称原子事务：如果原回应取消成功而新回应被服务器明确拒绝，保留“原回应已取消”的事实，允许稍后重新选择。

网络失败可能发生在服务器已写入之后，因此不自动重发 POST。请求前持久化 pending 标记；结果不明时暂停这条动态在该浏览器中的再次写入（刷新页面也不会盲目重试），仍可刷新累计数量。单纯读取总数无法确定匿名用户那次写入是否成功；需要维护者核对后处理本机记录，不能根据数量猜测恢复。存储不可写时仅显示数量，不发送回应。

## 验证

`pnpm exec vitest run tests/unit/moment-reactions.test.ts` 覆盖协议、确认后的增减、切换部分失败、未知结果不重复提交、本机存储失败、过期读取响应、预览停用、切页和追加动态。

`pnpm exec playwright test tests/e2e/moment-reactions.spec.ts` 覆盖折叠展示、零计数隐藏、选择后出现及取消归零消失、Escape / 外点关闭、焦点返回、窄屏选择网格，以及既有取消、切换、失败恢复和分页行为。测试以本地构建模拟正式 Origin，拦截全部 Waline 请求，不写入生产计数。控件截图输出到 `output/playwright/`。

部署前在真实允许 Origin 下只读核验六项计数；用户操作或隔离测试才会写入。现有服务已支持此接口，不需要新增密钥配置。
