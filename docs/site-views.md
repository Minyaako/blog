# 网站访问量

首页个人介绍条和 `/about/` 展示「本站访问」。这是从功能上线起累计的全站页面访问次数（PV），不是独立访客数，也不回填之前不存在的历史访问量。

所有使用 BaseLayout 的生产页面共享 Waline 的 `__site_pageviews_v1__` 计数键，复用已验证的 `/api/article` 计数接口。首次加载、Astro 切页、浏览器返回缓存恢复各记录一次；重复初始化和同页锚点不会额外记录。即使当前页没有显示徽章，页面访问仍计入全站总量。文章阅读量继续按文章 ID 独立累计。

只有精确生产域名 `https://gsk.minyako.top` 且非公开预览构建才会请求计数。请求超时或失败时显示「暂不可用」，不会伪造数字，也不会自动重试可能已经写入的 POST。计数不影响正文展示或导航，切页后会取消旧请求并忽略旧页面返回值。
